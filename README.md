# Верстак 🧰

Бесплатные онлайн-инструменты без регистрации. Всё работает в браузере, файлы никуда не загружаются.

**20 инструментов:** сжатие картинок, QR-коды, генератор и проверка паролей, счётчик слов, очистка текста,
JSON-форматтер, минификатор CSS/HTML, конвертер единиц, тест скорости печати, помодоро-таймер, цвета и палитры,
оптимизация ПК (чек-лист + тест), Base64/URL, проценты, тест экрана, рандомайзер, калькулятор дат, заметки,
тест реакции, генератор ников. Плюс страница «Тренды», избранное, поиск, тёмная/светлая тема, офлайн-режим.

## Посмотреть у себя
Просто открой `index.html` двойным щелчком.

## Выложить в интернет (GitHub Pages, бесплатно)
1. Один раз: `gh auth login --web` (войти в GitHub).
2. `powershell -ExecutionPolicy Bypass -File deploy.ps1`
3. Сайт появится по адресу `https://<твой-ник>.github.io/verstak/`.

Чтобы обновить сайт после изменений — снова запусти `deploy.ps1`.

## Как добавить инструмент
В `js/tools.js` добавь блок `add({ id, name, icon, cat, desc, tags, render(root) { ... } })`.
